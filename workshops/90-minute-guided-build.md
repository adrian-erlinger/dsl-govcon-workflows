# 90-Minute Overview and Guided Build

## Default Path

The default guided build is Opportunity Triage and Bid/No-Bid Brief. A facilitator may substitute another workflow when the audience has a stronger need.

## Learning Outcomes

Participants will:

- understand the permitted-data and professional-advice boundaries;
- use a structured prompt with synthetic inputs;
- create a draft Markdown workflow aid;
- inspect a Codex diff;
- identify unsupported assumptions and revise the draft.

## Run of Show

| Time | Activity |
|---|---|
| 0–10 minutes | Welcome, GovCon context, outcomes, and boundaries |
| 10–20 minutes | Repository orientation and prompt anatomy |
| 20–35 minutes | Inspect synthetic opportunity inputs |
| 35–55 minutes | Run the prompt and create the draft brief |
| 55–70 minutes | Review the diff and trace findings to sources |
| 70–83 minutes | Revise one weak assumption and adapt one field |
| 83–90 minutes | Governance recap, reflection, and close |

## Completion Standard

A participant completes the session by producing and reviewing a draft—not by accepting every Codex change. The output requires qualified human review and is not ready for live procurement use.
