# 3-Hour Hands-On Lab

## Flexible Selection

The facilitator may cover one, two, or three workflows depending on audience, pace, and time. Completing all three is not required.

Choose the path before the session using the [Workflow Downselection Guide](../facilitator/workflow-downselection-guide.md). If the group needs more review time, reduce the number of workflows rather than rushing.

## Learning Outcomes

Participants will:

- build at least one structured workflow aid from synthetic inputs;
- compare source facts with Codex analysis;
- inspect and revise file changes;
- use explicit ownership, evidence, risk, and question fields;
- identify governance steps required before organizational use.

## Suggested Run of Show

| Time | Activity |
|---|---|
| 0–15 minutes | Welcome, repository orientation, safety, and review expectations |
| 15–50 minutes | Selected workflow 1: inspect, build, and review |
| 50–90 minutes | Selected workflow 2 or deeper revision of workflow 1 |
| 90–100 minutes | Break |
| 100–140 minutes | Selected workflow 3, workflow 2, or adaptation exercise |
| 140–160 minutes | Cross-workflow review and correction |
| 160–175 minutes | Governance discussion and safe adaptation |
| 175–180 minutes | Reflection and close |

## Path Options

- **One workflow:** Deep build, two review passes, and a synthetic adaptation.
- **Two workflows:** Full build-and-review cycles for two audience-aligned needs.
- **Three workflows:** Compact, time-boxed builds with one shared review cycle.

## Facilitator Checkpoints

- Stop input use if any participant introduces non-synthetic material.
- Require at least one source challenge per workflow.
- Preserve time for qualified-review and governance discussion.
- Remind participants that output completeness is not guaranteed.

## Completion Standard

Participants succeed when they can explain how an input became a draft output, identify a weakness, and revise it. The number of workflows completed is not the measure of success.
