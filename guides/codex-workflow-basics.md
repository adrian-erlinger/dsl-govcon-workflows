# Codex Workflow Basics

Codex can read files, propose changes, and show you what changed. In this training, you will use it as a drafting partner—not as an authority.

If you are opening Codex for the first time, start with [Codex Setup and Navigation](codex-setup-and-navigation.md).

## The Five Parts of a Useful Prompt

1. **Purpose:** Say what internal workflow aid you want.
2. **Inputs:** Name the files Codex may use.
3. **Outputs:** Name the files and fields Codex should produce.
4. **Boundaries:** State what Codex must not infer or do.
5. **Review:** Require missing information, uncertainty, and human-review notes.

## Helpful Habits

- Read the input before running the prompt.
- Ask Codex to cite the input field or section behind each conclusion.
- Prefer “unknown” over an invented answer.
- Treat scores as discussion aids, not mathematical truth.
- Ask what evidence would change a recommendation.
- Review the proposed file changes line by line.

## If Codex Is Uncertain

Codex should label the item as unknown, explain why, and add a question for the appropriate reviewer. It should not silently fill gaps.
