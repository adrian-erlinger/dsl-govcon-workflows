# The Codex Workflow

This workshop is about learning how to work with Codex on reviewable files.

Think of this repository as a workbench. The workbench contains source materials, prompts, templates, draft outputs, review notes, and revisions. Codex can work inside that workbench, but you remain responsible for deciding what is useful, accurate, and ready to keep.

## The Review Loop

Read → Inspect → Prompt → Review → Question → Improve → Repeat

If you remember one thing from this workshop, remember this:

**Do not judge Codex by the prompt you gave it. Judge it by the work it proposes and the review you perform.**
