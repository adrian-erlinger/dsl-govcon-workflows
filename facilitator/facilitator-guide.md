# Facilitator Guide

## Purpose

This workshop helps GovCon professionals build repeatable, reviewable workflow aids with Codex. The teaching emphasis is disciplined file-based work, source traceability, and human judgment.

This is not a general AI demonstration and does not provide legal, procurement, compliance, pricing, cybersecurity, or proposal advice.

## Before the Session

1. Read [Safety and Boundaries](../SAFETY-AND-BOUNDARIES.md).
2. Choose the delivery path using the [Workflow Downselection Guide](workflow-downselection-guide.md).
3. Complete the [Setup Checklist](setup-checklist.md).
4. Review the synthetic inputs and expected-output guides.
5. Decide which optional sections of the [Slide Outline](slide-outline.md) to use.
6. Keep the [Troubleshooting Guide](troubleshooting-guide.md) available.

## Teaching Pattern

For each selected workflow:

1. State the practical pain point.
2. Inspect the synthetic inputs as a group.
3. Identify known facts and missing information.
4. Run or adapt the workflow prompt.
5. pause before accepting changes.
6. Inspect the diff and trace findings to sources.
7. Ask participants to find one weak assumption.
8. revise the draft.
9. Apply the human-review checklist.

## Facilitation Principles

- Show that a useful workflow is a sequence of reviewable files, not a magic answer.
- Reward participants for finding uncertainty and rejecting unsupported output.
- Treat first drafts as raw material.
- Avoid specialized technical language when plain language works.
- Never invite participants to paste live organizational material.
- Do not describe an extraction, score, or recommendation as complete or authoritative.
- Route specialist questions to appropriately qualified personnel.

## Closing Message

Participants should leave able to adapt a safe file-based pattern, not with an unreviewed answer ready for submission. Reiterate that every output is a draft internal workflow aid requiring qualified human review.
