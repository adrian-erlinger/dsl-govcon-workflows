# Troubleshooting Guide

## Codex Invents a Fact

Ask Codex to remove every claim that cannot be traced to an approved input. Add the missing item as an explicit question instead.

## The Output Is Too Generic

Point Codex to the required template fields. Ask it to cite a source for each material finding and explain each score or risk.

## The Output Sounds Too Certain

Ask Codex to separate source facts, analysis, assumptions, and unknowns. Replace definitive language with bounded draft language.

## The CSV Is Hard to Read

Check that each row represents one item and each column represents one consistent field. Avoid putting long lists into a single cell.

## The Group Is Moving Slowly

Finish the current workflow's review cycle. Skip another workflow or demonstrate only its input-to-output pattern. In the 3-hour lab, covering one, two, or three workflows is acceptable.

## A Participant Wants to Use Live Data

Stop that action. Return to the provided synthetic files. Explain that any later organizational use requires separate governance and approval.

## A Specialist Question Arises

Record the question and identify the qualified role that should answer it. Do not improvise legal, procurement, compliance, pricing, cybersecurity, or proposal advice.
