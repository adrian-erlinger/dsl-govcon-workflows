# Facilitator Setup Checklist

## Repository

- [ ] The repository opens correctly for the facilitator.
- [ ] `START-HERE.md` links to both workshop paths.
- [ ] Each selected workflow includes instructions, a prompt, data, templates, and an expected-output guide.
- [ ] No participant needs to install packages or connect an external service.

## Safety

- [ ] Participants have received the synthetic-data rule.
- [ ] Participants know not to paste real company, client, proposal, or procurement data.
- [ ] Participants understand that secrets, confidential information, and proprietary material are prohibited.
- [ ] The professional-advice boundary is visible.
- [ ] Qualified human review is included in the planned debrief.

## Delivery

- [ ] The selected workflows match the audience and time.
- [ ] Time checkpoints are visible to the facilitator.
- [ ] Synthetic input files have been reviewed in advance.
- [ ] A stopping point is selected if the group moves slowly.
- [ ] The facilitator can demonstrate how to inspect a diff.
- [ ] The reflection and governance discussion have reserved time.
