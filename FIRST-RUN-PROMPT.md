# First-Run Starter Prompt

Start here if you are opening this repository in Codex for the first time. This 15-minute exercise uses only the repository's fictional, synthetic source packet.

You will create two draft Markdown files, inspect the proposed changes, and challenge one claim before accepting anything. The files are practice aids, not final business recommendations.

Copy this into Codex:

```text
I am a first-time user of this GovCon training repository. Guide me through a 15-minute synthetic Opportunity Triage exercise.

Start by reading:
- START-HERE.md
- SAFETY-AND-BOUNDARIES.md
- workflows/opportunity-triage/README.md
- workflows/opportunity-triage/instructions.md
- workflows/opportunity-triage/data/source-packet-index.md
- workflows/opportunity-triage/prompt.md

Use only the synthetic source files named in the Opportunity Triage source packet. Do not use web sources, real opportunities, or real company information.

Before editing, explain:
- the synthetic sources you will use;
- one known fact, one unknown or weak point, and one item a qualified reviewer should check;
- the two draft files you plan to create.

Then state that no files have been created yet, ask for my explicit approval to create the two drafts in workflows/opportunity-triage/outputs/, and stop until I answer affirmatively.

Use a coaching tone. Briefly explain why each next step matters. Separate source facts from analysis, preserve uncertainty and conflicts, cite source files or fields, and treat scores as discussion aids rather than final decisions. Route open questions to reviewer roles and state that the drafts require qualified human review.

After I approve creation, tell me what changed and ask me to review one claim by tracing it back to its source.
```

After this first run, try a public opportunity with the detailed [Public SAM.gov Practice Reference Prompt](FIRST-RUN-REFERENCE-PROMPT.md).
