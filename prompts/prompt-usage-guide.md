# Reusable Prompt Usage Guide

The prompts in this folder are reusable templates for later adaptation. They are not the starting point for a first-time user.

If you are new to Codex, begin with `START-HERE.md` and use the prompt inside `workflows/opportunity-triage/prompt.md`. That workflow shows the prompt in context, with the source files and draft outputs it is meant to use.

The prompts in this folder are designed to be copied, reviewed, and adapted after you understand the Opportunity Triage workflow pattern.

## Before Using a Prompt

- Verify that every named input is synthetic and approved.
- Read the output template.
- Replace only the clearly marked choices.
- Keep the safety and review language intact.

## After Using a Prompt

- Inspect the diff.
- Compare outputs with source inputs.
- Ask Codex to explain weak conclusions.
- Correct the draft.
- Apply the human-review checklist.

These prompts create draft internal workflow aids only. They do not provide legal, procurement, compliance, pricing, cybersecurity, or proposal advice.
