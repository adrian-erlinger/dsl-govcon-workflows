# Reusable Prompt Usage Guide

The prompts in this repository are designed to be copied, reviewed, and adapted.

## Before Using a Prompt

- Verify that every named input is synthetic and approved.
- Read the output template.
- Replace only the clearly marked choices.
- Keep the safety and review language intact.

## After Using a Prompt

- Inspect the diff.
- Compare outputs with source inputs.
- Ask Codex to explain weak conclusions.
- Correct the draft.
- Apply the human-review checklist.

These prompts create draft internal workflow aids only. They do not provide legal, procurement, compliance, pricing, cybersecurity, or proposal advice.
