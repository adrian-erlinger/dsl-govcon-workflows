# Reusable Prompts

This folder contains reusable prompt templates for later adaptation.

Do not start here if you are new to Codex. Start with `START-HERE.md`, then use the prompt inside `workflows/opportunity-triage/prompt.md`. The Opportunity Triage workflow shows a prompt in practice with its source files, templates, draft outputs, and review steps.

Use these reusable prompts only after you understand the basic workflow pattern.
