# Opportunity Triage Outputs

Codex writes generated Opportunity Triage practice drafts here. This folder starts with this README only; the draft files appear after you run an exercise.

When you run the fully synthetic first exercise, Codex creates these filenames using the synthetic opportunity ID:

- `draft-opportunity-intake-SYN-DCS-2030-014.md`
- `draft-bid-no-bid-brief-SYN-DCS-2030-014.md`

When you later run the optional public SAM.gov exercise, Codex creates filenames that include that opportunity's solicitation number. For example:

- `draft-opportunity-intake-N0003926R9450.md`
- `draft-bid-no-bid-brief-N0003926R9450.md`

Supplied completed drafts are kept in [examples/opportunity-triage](../../../examples/opportunity-triage/) so learners can distinguish examples from their own generated work. Generated drafts are internal workflow aids for review, not final bid/no-bid decisions.
