# Opportunity Triage Outputs

Codex writes generated Opportunity Triage practice drafts here. This folder starts with this README only; the draft files appear after you run an exercise.

When you run the guided public SAM.gov exercise, Codex creates filenames that include that opportunity's solicitation number. For example:

- `draft-opportunity-intake-N0003926R9450.md`
- `draft-bid-no-bid-brief-N0003926R9450.md`

When you run the fully synthetic rehearsal, Codex creates these filenames using the synthetic opportunity ID:

- `draft-opportunity-intake-SYN-DCS-2030-014.md`
- `draft-bid-no-bid-brief-SYN-DCS-2030-014.md`

The examples above are filenames, not files supplied with the repository. Generated drafts are internal workflow aids for review, not final bid/no-bid decisions.
