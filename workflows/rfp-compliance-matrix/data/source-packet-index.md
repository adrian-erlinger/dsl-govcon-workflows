# RFP Compliance Matrix Synthetic Source Packet

> Training data only. Every organization, person, date, solicitation, attachment, requirement, role, and fact in this packet is fictional.

Use this packet to practice extracting requirements into a draft compliance matrix and responsibility tracker. The files are intentionally incomplete and contain ambiguities that should become reviewer questions.

## Approved Source Files

Read these files before running the RFP Compliance Matrix prompt:

1. `synthetic-rfp-excerpt.md` - fictional solicitation excerpt with core sections, page limits, deadlines, and attachments.
2. `synthetic-submission-instructions.md` - fictional portal, file-naming, packaging, and submission constraints.
3. `synthetic-evaluation-factors.md` - incomplete fictional evaluation factors and review caveats.
4. `synthetic-amendment-log.csv` - fictional amendment records that change or clarify selected requirements.
5. `synthetic-qa-log.csv` - fictional Q&A entries, including unanswered questions.
6. `synthetic-deliverables.csv` - structured deliverable list derived from the synthetic RFP excerpt.
7. `synthetic-team-roles.csv` - synthetic response-team roles, review boundaries, and routing guidance.

## How To Use The Packet

- Treat the files as source material, not as a completed matrix.
- Extract distinct requirements into separate rows.
- Preserve source references and amendment impacts.
- Treat unanswered Q&A and missing instructions as review items.
- Route specialist questions to roles, not invented people.
- Do not infer legal, pricing, cybersecurity, or compliance conclusions.
