# RFP Compliance Matrix Outputs

Codex writes generated RFP Compliance Matrix practice drafts here. This folder starts with this README only; the draft files appear after you run an exercise.

Expected draft files:

- `draft-compliance-matrix.csv`
- `draft-responsibility-tracker.csv`

These files are draft internal workflow aids for review. They may omit or misinterpret requirements and do not certify compliance.

Supplied completed drafts are kept in [examples/rfp-compliance-matrix](../../../examples/rfp-compliance-matrix/) so learners can distinguish examples from their own generated work.
